# 📊 Advertising Performance Dashboard (Power BI)

## 🚀 Project Overview
This project analyzes advertising performance across Google Ads, Meta Ads and TikTok Ads.

The dashboard helps businesses track Cost, Revenue and Profit across countries and industries.

---

## 🎯 Business Problem
Marketing teams spend huge budgets on ads but struggle to understand:
• Which platform performs best?
• Which country generates highest revenue?
• Which industry is most profitable?

This dashboard solves these problems using interactive visuals.

---

## 🛠 Tools & Skills Used
• Power BI  
• Excel  
• Data Cleaning  
• Data Visualization  
• Marketing Analytics  

---

## 📈 Key Insights
• Google Ads generated the highest revenue overall  
• TikTok performed strongly in India & Australia  
• Profit increased in March despite lower ad spend  
• SaaS & E-commerce industries dominated revenue  

---

## 📊 Dashboard Features
• KPI Cards (Cost, Revenue, Profit)  
• Country-wise performance map  
• Daily spend vs revenue trend  
• Industry-wise revenue breakdown  
• Platform comparison (Google, Meta, TikTok)
